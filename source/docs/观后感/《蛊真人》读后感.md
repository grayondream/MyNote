# 《蛊真人》读后感

&emsp;&emsp;前段时间换工作的间隙，没了往日繁忙的oncall，日子突然慢了下来，便尝试重试阅读的习惯。无意中与《蛊真人》这本暗黑小说相遇，本想来填补空白的时光，却不想跌入了它宏达的时间观和精巧的剧情设计中。整整一个月，我几乎沉浸在主角绝处逢生的转折中无法自拔。虽然整本小说的文笔算不上秀丽，但是那份其他网文少有的严禁逻辑和精妙设定，已经足够让我惊艳。

&emsp;&emsp;故事的起点是一个来自地球的平凡少年，跌落进了一个由蛊构成的奇幻修仙世界。蛊界的修行不问心，不问天地灵气，只求蛊虫变换无穷。从一转凡尘到九转巅峰，每一转都是天壤之别；五转以下为凡，六转退去凡尘，脱胎成仙。在这片诡谲的大地上，蛊是杀伐的冰刃也是大道的痕迹。蛊师们御真元，驭仙元，炼化世间无限奇虫，交织百千种蛊虫化作惊天动地的杀招，亦或是筑起坚不可摧的仙蛊屋。在这群仙环伺，万族林立的夹缝中，主角如同汪洋浮萍，在利用与反利用的罗网中挣扎，算计与反算计的棋盘中博弈，闯出属于自己的一片天地。他的生命被命运拆分成两段：第一世，他是漂泊五百年的魔道蛊仙，历尽沧桑尝尽人间炎凉；第二世，他携着五百年风霜和记忆逆流而上，卷土重来，以凡人之躯，步步为营，淬炼成掌握乾坤的棋手。
