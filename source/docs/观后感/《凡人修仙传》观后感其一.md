# 《凡人修仙传》观后感其一

## 前言
>&emsp;&emsp;这是我第一次写观后感，我觉得写观后感是一个非常好的习惯，它可以帮助我更好地理解自己的感受，也可以帮助我更好地表达自己的感受。

&emsp;&emsp;最近周末无聊，玩手机比较乏味空虚，我又不想动，因此在在网上找了一些动漫的推荐，想找一部动漫来看看。于是我参考了一些动漫博主的推荐，简单了解了一些日本和国内动漫的剧情，发现我对于日本动漫在我这个年纪大部分已经看不下去了，能看下去的都是一些日常和搞笑类的番剧。后来，经由同事推荐，开始看《凡人修仙传》动漫版本。

&emsp;&emsp;可能是因为常年对国产动漫的刻板印象，特别是国产的硅胶脸，让我对类似类型的动漫的印象一直不好。因此在看完第一集之后我并没有觉得很好。但是既然是同事强烈推荐，我也相信他的品味，因此继续看了下去。看到后面，我发现这部动漫的剧情非常有趣，而且也非常精彩。即便存在一些漏洞，但是也瑕不掩瑜。后来，我转念一想，日本动漫虽然配音不错，但是动漫任务的形象也就那样，瞬间心里的成见也就放下了。

&emsp;&emsp;虽然我现在只看到120集，但是我任务目前已经可以给这部动漫一个准确的定性的评价了，因此先写下这一篇观后感来记录我对这部动漫的评价。

## 剧情介绍
&emsp;&emsp;《凡人修仙传》是一部“凡人”修仙传，也就是没有修炼资质的人的修仙之路。小说的背景是一个玄幻世界，有凡人有修仙者，凡人有凡人的人间王朝，修仙者有仙人门的教门宗派。门派之间有不同的势力划分，不同的修炼体系，不同的功法传承。门派的势力划分是按照实力划分的，实力越强，势力越大。门派的修炼体系是按照等级划分的，等级越高，修炼体系越复杂。门派的功法传承是按照传承等级划分的，传承等级越高，功法传承越复杂。想要进入修仙门派修炼，需要有相关的机缘和条件，其中之一就是修炼资质，既灵根。灵根好的人就可以能进入修仙门派修炼，但是修炼资质好的人不一定能进入修仙门派修炼。

&emsp;&emsp;主角是一个只有伪灵根的凡人，按往常的规矩是很难进行修仙，但是主角无意中获得了属于自己的机缘——升仙令，成为了一个修仙者，开始了自己的修仙之路（这里省略了主角和墨前辈学习药物炼制的剧情）。由于主角是一个伪灵根的凡人，因此他的修炼资质是非常差的，因此他只能通过非常规的方法进行修仙。比如主角从最基本的练气进阶修仙的入门等级——筑基时采用了大量服用筑基丹的方式。对于主角来说虽然费时费力但是至少能够筑基成功。主角后续的从筑基完成结丹，也是通过非常规的方式，比如三次散功，从练气进阶到筑基，来完成结丹。现在看到的剧情主角还是结丹，估计后续达到元婴阶段的方式也是服用一些药物或者无意得到的机缘功法来完成进阶。

&emsp;&emsp;剧情展开围绕主角不断的修行进阶展开，主角的修炼之路非常曲折，但是也非常精彩。主角的修炼之路是一个非常复杂的过程，不同阶段需要的条件和难度天差地别，越往高阶修炼主角所面对的困难越大耗费的时间越久。每个阶段的套路基本都是收集草药，炼制丹药，炼制更高阶的法器来不断提升自己的实力帮助自己完成进入下一阶段。虽然每个阶段进阶的套路相似，但是作者在塑造主角时能够将前后贯通，塑造每个阶段所遇到的事和人，让主角的修行之路更加丰富真实。同时，主角和主角进阶的刻画也很现实，不会像其他修仙小说一样动不动就我命不由我不由天，分分钟秒杀高阶修士。下面就简单展开描述我觉得不错的剧情点：

**天南**
&emsp;&emsp;主角出厂于天南，前期的遭遇和大部分修仙类小说一样，没有特别之处。通过机缘进入宗派修炼，意外得到了某种宝物能够加快自己修炼的速度，从而筑基成功。主角在天南遭遇的最完美的情节分别为，墨前辈夺舍和被令狐作为弃子。墨前辈夺舍主角的剧情相比较一般，也算是开了一点点儿小挂，但是总体上无伤大雅。墨前辈和他背后的人以及主角韩立三个人互相防范互相利用，使得整个情节很有代入感。同时即便墨前辈被杀后，韩立和他女儿这条线一直贯穿天南让整个剧情能够串成一条线，非常顺滑。而主角被令狐作为弃子的剧情中主角所在宗门被灭，主角的师傅身死，而主角只能不断逃命，无法反抗让主角所在的世界更加真实。

**乱星海**
&emsp;&emsp;乱星海的展开相比于天南更加成熟。乱星海中不同势力明面、暗面的矛盾和利益纠葛让整个剧情更加真实。比如星宫、逆星盟和海妖三者之间的利益纠葛，不同势力相互敌对但又千丝万缕相互联系，不同势力中不同人的矛盾之处让整个情节相比于天南更上一层。

## 人物塑造
&emsp;&emsp;凡人的人物塑造也比较成功。主角形象比较真实，实力比较弱时就规避锋芒不强行出头，实力足够时就主动了解恩怨，快意恩仇。比如主角初入黄枫谷被其师伯强行索要药草时主角认怂，乱星海进入虚天殿时被蛮胡子强行要求让出位置，遇到修为比较自己高的人主角的优先考虑跑路而不是硬扛，面对高出一个境界的修仙者被人玩弄鼓掌之间只能利用高阶修仙者之间的矛盾逃生。

其他配角的塑造也故事感非常足，比如天南中李化元与结丹付师伯的纠葛，乱星海的玄骨的算计，乱星海凤希的阴谋等。

## 观感
&emsp;&emsp;剧情的展开和任务成长的节奏恰到好处，每几集都会有一段小高潮，不同小剧情又为大剧情服务，让整个剧情更加连贯，对于观者来说不断有爽点，能够让整个剧情更加有代入感。任务塑造也比较成功，没人任务都有自己的矛盾之处，并不是所有人都和主角要么有深仇大恨，要么就是至死不渝忠心耿耿，而是都各自心怀鬼胎，或者真的被主角的为人所影响而交友。总的来说凡人的剧情和人物都符合弱肉强食和利益至上的准则，让每个角色和每段剧情都很真实，同时辅以个人的真情和冲动让人物更加丰满，而不至于陷入俗套或者赤裸裸的社会达尔文。总的来说，凡人算是一部比较不错的修仙剧，在我心里算是前二的水准。
