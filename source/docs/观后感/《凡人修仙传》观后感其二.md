# 《凡人修仙传》观后感其二

&emsp;&emsp;距离第一次写《凡人》的观后感已过去大半年。这期间，我陆续看完了剧版、正版动画以及各类同人低成本动画，对这部作品也有了一些新的衍生思考。  

&emsp;&emsp;截至写作今日，动画版已推进至慕兰草原大战，同人动画基本更新至仙界，而剧版则刚触及乱星海的序幕。时至今日，我仍对国内仙侠电视剧抱有保留意见，此次尝试纯粹是冲着《凡人》的剧情而去。然而总体观感难言理想，角色、妆造及台词设计均未脱离当下流量剧的公式化套路。因此，本文将摒弃剧版，着重探讨正版动画与同人动画。后者虽多为粉丝发电或低成本制作，却因聚焦剧情内核，反倒能让人找回当年读小说的纯粹感。  

&emsp;&emsp;《凡人》本质上是一部经典的“主角逆袭史”。虽有掌天瓶这一至高金手指，但作者难能可贵地将一个无背景、资质差的凡人从底层修仙界走向巅峰的过程，进行了最大程度的合理化。主角的性格与剧情推演皆为此服务：韩立心思缜密、行事低调，遇事则谋定后动、斩草除根；若实力不济，则果断保存实力以待来日。人界篇将这些特质体现得淋漓尽致。无论是黄枫谷时期借魔道入侵顺势脱离宗门，还是利用大阵与传送令转战乱星海，剧情始终在制造冲突、利用冲突，将主角的成长轨迹严丝合缝地嵌入大势的缝隙中，跌宕起伏而不失逻辑。遗憾的是，后续的灵界篇与仙界篇未能打破这一框架，灵界尚有创新，仙界则几乎沦为同类套路的疲惫复刻，随着设定合理性的逐步崩塌，原著在后期也失去了继续追读的必要。  至于备受瞩目的正版动画，走到今日，我的态度已由期待转为失望。截至183集，虽然《乱星海篇》制作上乘，《天南篇》开局也算中规中矩，但近期剧集在情感线上的刻意编排却令人反感。一个历经两三百年风雨、见惯生死背叛的修仙者，可以有情，但绝不能“情字当头”。让韩立在离开天南数百年后，与女主重逢便迅速建立起如胶似漆的情感联系，这严重违背了一个成熟修仙者的行为逻辑。我更期望看到的，是两人相遇时各带着几分利益的审视、小心翼翼的试探，在旧情与现实的拉扯中，通过风雨同舟再度走近。唯有这种带着克制的温存，才符合韩立历经磨难的心路历程。其实从去年动画组对慕沛灵人设的魔改开始，这种向“恋爱脑”妥协的趋势便已初见端倪。既然已经在同人动画中得知了后续剧情，正版动画我也就不打算再追了。
