# 《灵笼》观后感

&emsp;&emsp;最近在朋友的推荐下看了下比较火的国产3D动漫——灵笼。动漫本身截止写作日期还没有更新完，但是在我心里对其的定位已经比较明确。先简单笼统的说一下总体感受，能看到制作组希望将该动漫制作成高水平高质量的作品，但是很明显导演编剧对整体的剧情的把控恨不到位，导致整部动漫有骨无肉。

&emsp;&emsp;动漫的背景设定是在一个科技尚可的末世。人类由于被一种生物攻击被迫只能在少部分地区生存（怪物能够吸收人类的生命源质将人类石化，且很难杀死），包括持续漂浮的空中城市，地上少数区域。

&emsp;&emsp;目前动漫分为两季，第一季剧情主场为空中城市。主角最初就是出生在空中城市中，按照动漫的设定城市为了保障其可持续的运行，进行了一次改革。改革的措施包括：人种优选，剥夺劣质基因的生育权来利益最大化城市资源的消耗；定期派遣先遣队（剧中具体的名称我忘了）前往地面搜集城市中无法快速生产的物资。而主角作为该先遣队的队长经常需要前往地面面对凶残的怪物，以此为故事线展示叙事揭露整个城市中不同群体之间的矛盾。比如城主和宗教团体之间的矛盾，主角和城主儿子之间的矛盾，宗教和下层人民之间的矛盾，其中主线是城主儿子不满城主将位子传给主角而对主角进行各种陷害，但是主角并没有像其他王道漫画那样逆袭，而是在一次意外中被怪物寄生，最终经过偏执医生的努力完成了第二次重生——拥有人类感情的怪物。由于主角变成怪物，其他很多人不明真相的人无法理解，再加上城主儿子的推波助澜导致主角在被持续欺辱的过程中错误的吸食了其女友的生命源质而爆发兽性对主城进行攻击，从而导致和城市中人的矛盾进一步激化。

&emsp;&emsp;第二季的剧情转移到了地面。主角在第一季与空中城市互相攻击的过程中掉落到了地面，被地面上幸存的人救回。而参与救回主角的人群可以称之为第二主角团。第二主角团隶属于地面上一个在怪物之间找到生存地带的村子，而他们救回主角的原因似乎知道些什么。后面的剧情基本展开就是主角以怪物的身份融入新环境，在地面再次探险来揭开怪物之谜的线路。

&emsp;&emsp;剧情基本说完了，简单谈下我对整部动漫的感官。我看完第一季的感觉是动漫有很深的《进击的巨人》和《西部世界》的影子，前者更深。都是在末世（虽然最终不是），通过冒险来揭开世界之谜，通过剧情设计沙掉主角身边的人来推动剧情。虽然说有巨人很深的影子，但是我个人觉得无所谓，如果能够做到巨人前期那种高度那必然是这几年最好的动漫。但是问题是他没有做到。
&emsp;&emsp;在吐槽之前先说一些我比较喜欢的点，动漫第二季第二集中将国内的枪法运用到战斗场景对于作为国人的我来说非常喜欢，从这一点上能感觉到技术团队有在用心做东西。但是整部动漫的剧情编排差强人意，能感觉到编剧期望将巨人中那种抽丝剥茧的感觉带给观众但是实际上做到的是抽丝破茧，并没有剥洋葱那种爽快感。另外作为这个剧情大背景的渲染也不到位，按照设定主角的环境是末世，但是制作组却整出了民间农村养老院的场景。编剧塑造末世的唯一方式就是杀人，不断的杀掉主角身边的人。另外，编剧期望通过动漫感染观众，让观众流泪没问题，但是总是喜欢强行煽情，很多一个小镜头就能渲染出来的内容非要花费大量篇幅去渲染，就显得很蹩脚，甚至尬到抠脚趾。

&emsp;&emsp;总的来说，作品质量不高，有可圈可点之处，但是槽点太多，用鸡肋来形容是非常贴切的。因此我已经放弃继续观看了。
